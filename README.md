# Swarm battle

A playable prototype: four players, planets producing glowing units, swarms flying between planets,
capture and annihilation. Blue is yours: tap or click one of your planets to select it (Shift adds; tap it again to let go),
then another planet to send half of the selected units there; keys 1–0 set the share. You see only what your planets can see: the rest is fogged, remembered as last seen.

Built with Godot 4.7.2 (web export, single-threaded). Play: https://dveyarangi.github.io/swarm-battle/
